# Security policy

This repository accepts only synthetic property, room-type, local-date, inventory, quote, hold, booking, cancellation, and failure
fixtures. Do not report or attach real credentials, guest/property/staff identities, contact or payment data, confirmation codes,
access tokens, production rates, occupancy, financial records, topology, storage paths, or internal reservation metadata.

For a suspected repository vulnerability, open a GitHub security advisory when a public remote exists. Public issues are suitable
only for non-sensitive correctness bugs. This laboratory is not a deployed booking, payment, property-management, identity, or
room-access system.
